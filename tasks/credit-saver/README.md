# How to Use Skill README

✅ Overview

This skill file provides clear instructions for helping an AI agent complete a specific task with consistent, high-quality output.

✅ How to Use

Upload `SKILL.md` directly into the skill upload section of your chosen application. (Claude, etc.)

After uploading, name it then test the skill with a simple request to make sure the output matches your intended workflow.

✅ Best Practices

A strong skill file should be:

- Specific yet concise to guide the assistant
- Focused on the user’s desired outcome
- Tip use / in agent mode to trigger your skill 

✅ Writing Guidelines

Use clean Markdown formatting.

Recommended formatting:

- Short sections
- Simple headings
- Bullets for steps or rules

Avoid:

- Long explanations!
- Overly complex rules (increase token usage)

✅ Quality Checklist

Before using the skill, confirm that it:

- Has a clear purpose
- Explains when it should be used
- Defines the ideal output
- Includes any required inputs
- Gives the assistant a simple workflow
- Avoids unnecessary restrictions
- Can be reused in different environments

🤓 Notes

This README explains how to use and customize the skill file it does not need to be uploaded.
